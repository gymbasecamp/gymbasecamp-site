# BASECAMP — 시즌 1 · 정상 쟁탈전 (스토리 바이블)
지훈 지시(2026-11-13): "릴스·카드뉴스의 스토리를 만들어 봐. 이전 것과 연결되게, 우리만의 재미있는 스토리. 사람들은 스토리에 반응한다."

## 세계관
- 에베레스트 산맥 = 9개 종목 봉우리(사이트 홈의 3D 산맥과 같다). 정상 = 종목 1위.
- 브랜드 = 정상을 노리는 선수/등반가. 점수 = 고도. 매일 바뀌는 실제 점수 = 등반 기록.
- 화자 = "베이스캠프 통신"(우리 계정). 중계하듯 짧고 긴장감 있게. 마스코트·실존 인물은 그리지 않는다.
- 회차 = 릴스 EP 번호가 곧 화수(EP.14 HYROX 레이스가 1화 격). 번호는 계속 이어진다.

## 회차 구조(모든 메인 릴스)
1. **지난 화(0~1.9초)**: 바로 전 회차의 결말 한 줄. story.js 오버레이(STORY json의 prev).
2. **본편**: 종목별 대회(레이스·토너먼트·기록전).
3. **다음 화 예고(마지막 2.8초)**: 다음 회차 종목과 관전 포인트 한 줄 + 댓글 질문(next, ask).
   - 예고는 반드시 실제로 다음에 올릴 종목이어야 한다. 다음 회차를 만들 때 예고를 지킨다.
   - 결과를 미리 약속하지 않는다(“~할까?”로 끝낸다).
4. 캡션 첫 줄도 이야기로: “[EP.N] 지난 화 ○○… 오늘은 ○○.” 마지막에 “다음 화: ○○”.

## 진짜 데이터만으로 만드는 긴장감(지어내지 않는다)
- 왕좌 교체: 어제와 1위가 다르면 최우선 소재.
- 추격전: 1~2위 점수 차 2점 이하면 "○점 차 추격".
- 급상승: 최근 3일 +5점 이상 → "어디서 나타났나". 왜 올랐는지(정보 확인·구매처 확인 등) 솔직히 말한다.
- 독주: 2위와 5점 이상 차이 → "독주는 언제 깨질까".
- 데뷔: 새로 추가된 브랜드가 TOP5 진입.
- 이벤트: 실제 대회(예: HYROX 서울 11/13–15), 시즌 세일(블프)과 연결.
- 점수 변화 이유는 사이트 점수 기준 그대로. 이야기를 위해 순위·점수·공식을 바꾸지 않는다.
