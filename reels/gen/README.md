## 콘텐츠 속도감 원칙 (지훈 학습 2026-11-14 — 모든 릴스·카드뉴스에 적용)
출처: 지훈이 공유한 릴스 강의("말의 속도감 vs 영상의 속도감"). 좋은 영상 = 시청자가 무엇을 느끼게 할지에 맞춰 속도를 조절하는 영상.
- **정보 구간**(순위·점수·규칙·기록·가격) = 이해의 속도. 첫 1초 안에 훅, 숫자는 크게 바로, 빈 화면·멈춤 0.5초 넘기지 않기. 한 화면엔 한 메시지. 공개가 끝나면 바로 다음으로.
- **미감 구간**(선수 실루엣·경기장·브랜드 분위기·엔딩) = 감상할 여유. 음악·카메라는 차분하게, 대신 컷을 바꿔 시각적 속도를 만든다(전신 ↔ 몸통 브랜드명 클로즈업 ↔ 발·장비 디테일 ↔ 관중/조명). 컷은 비트에 맞춘다.
- 컷을 무조건 많이 넣지 않는다 — 글자(말)와 화면의 리듬을 맞춘다. 글자가 읽히는 동안엔 화면을 크게 흔들지 않는다.
- 엔딩 카드는 2.5초 안팎, 다음 화 예고(2.8초)와 겹쳐 지루한 정지 구간이 없게.
- 카드뉴스: 정보형 → 장당 메시지 1개, 큰 숫자/결론 먼저, 설명은 2줄 이하. 감성형(선수 열전) → 여백 넉넉히, 디테일 이미지와 글을 번갈아.
- 짧은 릴스 '오늘의 브랜드' → 정보형 리듬(0.3초 안에 브랜드명, 1.5초마다 새 정보).
- 새 영상마다 키프레임 점검 때 "빈 구간(아무것도 안 바뀌는 0.7초 이상)"이 있는지 확인하고 줄인다.
